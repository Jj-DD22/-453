# 快手自动化剪辑工作台（第一版 · 原版 / 第二版 · 栋哥组）

本机工作台提供 **第一版 · 原版** 和 **第二版 · 栋哥组**。两个版本共用素材池、SQLite 持久化任务队列与下载入口：
- **第一版 · 原版**：保留 8038 原版智能自然切分混剪与批量相似度核验。
- **第二版 · 栋哥组**：默认启用「全部核心独立预览／裁剪＋多核心自动轮换开场＋开头核心声画原样保口型不动＋剩余原声与后续核心完整原声自动接续配打乱」，并内置 **9 项全自动多维深度去重**（跨条零重复抽换账本、剪点随机错位与总时长 ±15%～20% 安全梯度错开、多源禁同源连切、逐镜 1.05～1.15x 微缩放与 XY 位移、0.9～1.1x 随机变速与抽补帧节奏、曲线＋HSL 独立微调色、5%～12% 柔光光斑与胶片微粒滤色叠底、自然环境微底噪＋微 EQ＋后半段无口型原声保音高微调速、独立 GOP/码率浮动与元数据剥离＋防重交付文件名），同时支持手拉字幕遮挡框与底部叠图。

## 目录结构

- `app/`：单机 / 局域网工作台完整前后端与剪辑渲染内核（默认监听 `8038` 端口，兼容 macOS Apple Silicon VideoToolbox 与 Windows NVIDIA NVENC / Intel QSV / CPU）
  - `v16_web_app.py`：Web 工作台服务、素材池管理、多核心独立裁剪与音画模式配置、9:16 框选挡字、底部叠图及持久化制作队列
  - `run_v16_enhanced.py`：多轨视频混剪、贴纸叠加、成片画质与输出规格合同校验主引擎
  - `dongge_fixed_render.py`：栋哥组时间轴渲染引擎（开头核心声画原样保护＋打乱段多维画面/音频/编码深度去重）
  - `audio_preserving_edit.py` / `original_audio_job.py`：多核心开场轮换、原声精确口型对齐、尾音与后续核心原声连续接力、总时长错开与批量验收调度
  - `shuffle_order.py` / `visual_shuffle.py` / `shuffle_history.py`：跨条零重复选镜账本、多源禁连切编排与 48 帧双轨 dHash 历史查重数据库
  - `bottom_overlay.py`：打乱段字幕遮挡框（高斯模糊／去水印擦除／深色遮罩）与底部动态微抖动叠图模块
  - `hardcut_audio.py`：固定秒数硬切排片、Edge-TTS / CosyVoice / 系统语音合成及背景音乐混流引擎
  - `opening_video.py`：片头视频与核心原片无损前置处理模块
  - `task_queue_store.py`：SQLite 持久化任务队列存储与全版本一键重做支持
  - `assets/`：栋哥组前端交互脚本样式、滤镜纹理、人脸关键点模型与预览静态资源
  - `tests/`：时间轴编排、去重调度、兼容性与队列单元测试
- `server_8020/`：多用户 GPU 服务器版（`8020`）扫码隔离网关、并发槽位调度与局域网直传扩展模块
- `启动8038_Windows.cmd` / `启动快手硬切配音版_8038.command`：Windows / macOS 双击一键启动器
- `使用说明.md`：功能与操作说明

## 快速启动

本机 Windows 版可双击 **启动8038_Windows.cmd**，在浏览器打开 [8038 工作台](http://127.0.0.1:8038/#pools)。素材、队列和成片位于项目下的 `data`。本机启动器通过 `runtime` 引用已安装的 Python、FFmpeg、中文 OCR 和离线字幕模型。

1. 安装依赖（需系统已安装 `Python 3.10+` 与 `ffmpeg` / `ffprobe`）：
   ```bash
   pip install -r app/requirements_v16_web.txt
   ```
2. 启动本地工作台：
   ```bash
   python3 app/local_launcher.py --host 0.0.0.0 --port 8038
   ```
   浏览器将自动打开 `http://127.0.0.1:8038/#pools`。
